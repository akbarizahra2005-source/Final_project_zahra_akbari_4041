## توضیح پروژه
این پروژه یک صفحه ورود و ثبت‌نام حرفه‌ای با طراحی مدرن و کاملاً responsive است که فقط با **HTML، CSS و JavaScript خالص** ساخته شده.

### ویژگی‌های اصلی:
- طراحی دو بخشی زیبا با پنل معرفی و فرم
- سوئیچ بین تب‌های **Sign Up** و **Sign In**
- اعتبارسنجی پیشرفته پسورد با نمایش زنده وضعیت قوانین
- دکمه فقط وقتی فعال می‌شود که همه فیلدها معتبر باشند
- پیام موفقیت پس از ثبت‌نام یا ورود
- کاملاً **Responsive** روی تمام دستگاه‌ها
- استفاده از فونت Inter برای ظاهر حرفه‌ای

## تکنولوژی‌ها:
- HTML5
- CSS3
- JavaScript 

## نحوه مشاهده:
- لینک بالا را باز کنید و صفحه را تست کنید  
- یا فایل `index.html` را در مرورگر اجرا کنید
